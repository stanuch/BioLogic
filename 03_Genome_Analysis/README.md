# Genome Analysis

Restriction enzyme analysis on complete bacterial genomes.

## Topics Covered

- **Restriction Enzymes**: Recognition site identification and cutting simulation
- **E. coli Genome**: Analysis of the complete K-12 reference genome
- **Biopython**: Sequence parsing and manipulation
