# Biological Databases

Automated pipelines for accessing and processing data from biological and chemical databases.

## Topics Covered

- **NCBI E-utilities**: Programmatic access to PDB, PubMed, and sequence databases
- **PubChem/RDKit**: Chemical structure retrieval and physicochemical property calculation
- **TF-IDF Analysis**: Natural language processing for MeSH term extraction from scientific literature

## Files

| File | Description |
|------|-------------|
| `database_access.ipynb` | Main notebook demonstrating API access patterns |
| `utils.py` | Helper functions for data retrieval |
| `sequences.fasta` | Sample protein sequences |

## Key Techniques

- REST API integration with urllib
- SMILES parsing and molecular visualization
- Text vectorization for literature mining
