# Sequence Analysis

BLAST sequence alignment and data visualization with modern Python tools.

## Topics Covered

- **BLAST**: Local sequence alignment against custom databases
- **Polars**: High-performance dataframe operations for bioinformatics
- **Matplotlib**: Publication-quality visualizations

## Files

| File | Description |
|------|-------------|
| `blastn_polars.ipynb` | BLAST analysis with Polars dataframes |
| `matplotlib_visualization.ipynb` | Visualization techniques for sequence data |
| `markdown_and_magic_commands.ipynb` | Jupyter notebook best practices |

## Key Techniques

- Sequence database construction
- E-value interpretation
- Memory-efficient data processing
